# 4. Limites et intégration

La stabilité dépend des oracles, des seuils, des frais et de la liquidité. Le chapitre reste une lecture de code ; aucune installation, compilation, exécution ou test n’a été réalisé.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
