# 2. Stability Pool

Le Stability Pool absorbe les dettes liquidées et reçoit les collatéraux correspondants. Il mutualise le risque selon les dépôts et les règles de redistribution du protocole.

Ce chapitre relie le mécanisme au parcours d’exécution et signale les invariants que l’intégrateur doit préserver.
